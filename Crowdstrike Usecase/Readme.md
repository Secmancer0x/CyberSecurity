CrowdStrike Detection Lab

This repository contains a collection of SOC incident case reports based on simulated detections from CrowdStrike Falcon EDR, enriched with OSINT research and mapped to MITRE ATT&CK techniques.

📌 Purpose

The goal of this lab is to:

Practice professional incident documentation.

Build a structured case library mapped to MITRE ATT&CK.

Demonstrate the ability to use threat intelligence sources (VirusTotal, JoeSandbox, AbuseIPDB, MalwareBazaar, etc.) in investigation.

Provide a portfolio of real-world styled SOC deliverables.

🛠️ Tools & Sources Used

CrowdStrike Falcon EDR Alerts

OSINT Platforms: VirusTotal, JoeSandbox, AbuseIPDB, MalwareBazaar, FortiGuard

MITRE ATT&CK Framework for mapping tactics & techniques

📑 Report Structure

Each case report includes:

Case Information (Title, Date, Detection Source, Owner)

Incident Summary (Description, Severity, Classification)

Investigation Details (IoCs, OSINT findings)

MITRE ATT&CK Mapping

Timeline of Events

Result & Assessment (True/False Positive)

Recommended Actions (SOC + HR/Organizational)

Screenshots / Evidence
