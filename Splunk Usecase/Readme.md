# Splunk Detection Lab

This repository contains a collection of SOC incident case reports based on simulated detections from **Splunk SIEM**, enriched with OSINT research and mapped to MITRE ATT&CK techniques.

---

## 📌 Purpose

The goal of this lab is to:

- Practice professional incident documentation.  
- Build a structured case library mapped to MITRE ATT&CK.  
- Demonstrate the ability to use threat intelligence sources (VirusTotal, AbuseIPDB, Talos, FortiGuard, etc.) in investigations.  
- Provide a portfolio of real-world styled SOC deliverables.  

---

## 🛠️ Tools & Sources Used

- Splunk Enterprise Security (SIEM detections)  
- OSINT Platforms: VirusTotal, AbuseIPDB, Talos, FortiGuard  
- MITRE ATT&CK Framework for mapping tactics & techniques
